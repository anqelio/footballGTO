# Футбольное ГТО - Статический HTML/CSS сайт

Полностью готовый статический сайт для платформы тестирования футбольных навыков детей Уральского Футбольного Союза.

## Структура сайта
### Главная страница (index.html)

1. **Шапка (Header)**
   - Логотип УФС
   - Навигация по разделам
   - Телефон для связи
   - Адаптивное мобильное меню

2. **Промо-экран (Hero)**
   - Фоновое изображение футбольного поля
   - Заголовок с градиентом
   - Кнопки призыва к действию
   - Статистика проекта

3. **Форма записи на тестирование**
   - ФИО родителя
   - Телефон
   - Имя и возраст ребенка
   - Клуб (опционально)
   - Валидация полей

4. **О проекте**
   - Описание проекта
   - Три преимущества с иконками
   - Цитата от УФС

5. **Преимущества**
   - 6 карточек с описанием
   - Иконки для каждого преимущества
   - CTA-блок со статистикой

6. **Рейтинг лучших участников**
   - Вкладки: По показателям / По прогрессу
   - Переключение возрастных групп
   - Карточки топ-5 игроков
   - Кнопка перехода к результатам

7. **Мероприятия**
   - Галерея прошлых событий
   - Информация о дате, месте, количестве участников
   - Иконки видео для событий с видеоотчетами

8. **Контакты**
   - Форма обратной связи
   - Контактная информация
   - Покупка билета на тестирование
   - График работы

9. **Футер (Footer)**
   - Контакты
   - Социальные сети
   - Информация о проекте
   - Копирайт

### Страница результатов (results.html)

1. **Фильтры**
   - Поиск по имени
   - Фильтр по клубу
   - Фильтр по возрасту
   - Фильтр по полу
   - Сортировка по рейтингам

2. **Сравнение игроков**
   - Выбор нескольких игроков
   - Визуальное сравнение показателей
   - Очистка выбора

3. **Карточки игроков**
   - Фото игрока
   - ФИО, клуб, возраст
   - 7 рейтингов с визуализацией
   - Общий рейтинг
   - Прогресс (если есть)
   - Кнопка скачивания карточки

## Дизайн и стили

### Цветовая схема
- **Синий**: #2563eb (основной)
- **Красный**: #dc2626 (акцент)
- **Белый**: #ffffff (фон)
- **Серый**: #f9fafb, #e5e7eb, #4b5563, #111827 (текст и элементы)
- **Зеленый**: #16a34a (прогресс)

### Типографика
- Системный шрифт: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto

### Адаптивность
- **Mobile-first** подход
- Брейкпоинты:
  - 640px (sm) - планшеты
  - 768px (md) - планшеты в landscape
  - 1024px (lg) - десктоп

### Анимации
- Плавные переходы (0.2s-0.3s)
- Hover эффекты на кнопках и карточках
- Пульсация индикаторов
- Bounce анимация для scroll indicator

## Функциональность JavaScript

### Главная страница (script.js)

- **Мобильное меню**: Открытие/закрытие навигации
- **Рейтинг игроков**: Переключение возрастных групп
- **Табы**: Переключение между вкладками "По показателям" и "По прогрессу"
- **Формы**: Обработка отправки форм с валидацией
- **Моковые данные**: 10 игроков с полными характеристиками

### Страница результатов (results.js)

- **Фильтрация**: По имени, клубу, возрасту, полу
- **Сортировка**: По любому из рейтингов
- **Сравнение**: Выбор и сравнение нескольких игроков
- **Динамическое отображение**: Автоматическое обновление результатов
- **Моковые данные**: 10 игроков для демонстрации

## Моковые данные

Сайт использует тестовые данные для демонстрации:

- 10 игроков (8 мальчиков, 2 девочки)
- 3 возрастные группы (U-8, U-9, U-10)
- 3 клуба (Барса, Урал, Спартак)
- 7 категорий рейтингов
- 3 мероприятия с фотографиями

## Интеграция с бэкендом

Для подключения к реальной базе данных:

1. Замените моковые данные в `script.js` и `results.js` на API-запросы
2. Добавьте обработку форм с отправкой на сервер
3. Реализуйте генерацию PDF-карточек игроков
4. Подключите платежную систему для покупки билетов
5. Интегрируйте галерею с загрузкой изображений
